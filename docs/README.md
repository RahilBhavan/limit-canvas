# Limit Canvas documentation

This folder holds the reference, review and design documents for Limit Canvas. Start with the project [README](../README.md) for what it does and how to run it.

- [`why-limit-canvas.md`](why-limit-canvas.md): the problem with hand-built LOP extensions and what this project does about it.
- [`1inch-review.md`](1inch-review.md): a self-review written from a 1inch protocol engineer's point of view, with the P0, P1 and P2 list. It was not written by 1inch.
- [`packages/README.md`](packages/README.md): reference for each package (API, invariants, testing, gotchas).
- [`plan/README.md`](plan/README.md): the original design pack. These are historical planning documents, so some scope statements predate the current code.
- [`examples/gas-safe-stop-loss.manifest.sample.json`](examples/gas-safe-stop-loss.manifest.sample.json): a sample `manifest.json` from codegen.
- [`images/`](images/): the studio screenshot used in the README.
